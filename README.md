## Problem Statement

Write a C++ program to demonstrate the use of a class, constructor, destructor, and user-defined functions by implementing a simple **Restaurant Billing System** with user input.

## Objectives

1. To understand the concept of classes and objects in C++.
2. To implement constructors and destructors.
3. To create and use user-defined functions with user input.
4. To understand encapsulation in C++.

## Concepts Used

* Class
* Object
* Constructor
* Destructor
* User-defined functions
* Encapsulation
* Input and Output

## User-defined Functions

* `calculateBill()` calculates the total bill based on price and quantity.
* `updateQuantity()` updates the quantity of the food item.
* `display()` displays the order details and final bill.
